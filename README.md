# Python-Arduino-Data
# Arduino to Python Data Logger
## Description
The origin of the idea is the processing data, of the data recopiled of the sensor's, after used the data recopiled for the analysis.
The application used in the robot architecture system and the autonomous mobile system. The variable used is a different code,
which is the library of the sensor used.

## Software useed for the implemetations
- Arduino
- Python
- PySerial
- Pandas
- Matplotlib

## Data Flow
Arduino → Serial USB → Python → CSV → Data Analysis

## Use Cases
- Sensor monitoring
- Time series analysis
- IoT prototyping
- Data acquisition systems
